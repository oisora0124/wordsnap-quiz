# V2（新方式）への移行手順

## 開発者（自分）の手順

普段学習に使っている端末（スマホ等）で、いつもの個人リンクからWordBankを開いて実行する。

1. **設定** タブ →「🔄 データの保存・引き継ぎ」を開く
2. 中ほどの「**新方式（V2）の同期と引き継ぎ**」を開く
3. 「**新方式へ移行**」を押す
4. 表示された **引き継ぎコード**（`wr_….wk_…`）を保存する
   - 「テキストで保存」または「JSONを書き出す」で引き継ぎコードを同梱（推奨）
   - 「コードをコピー」だけでは端末外に残る保証がないため、保管したことにはならない
   - upgrade（移行）で得たコードは、**紛失しても従来の個人リンクからアクセスできる**。
     ただし再発行はできないので保管を推奨する
5. しばらく普段どおり使い、同期バッジが「同期済み」のままであることを確認する

### 他の端末も新方式にする場合（任意）

1. その端末が「同期済み」になっていることを先に確認する
2. 同じ画面の「**別の端末で引き継ぎコードを使う**」にコードを貼り、「このコードで合流」
3. すでに別のV2データと同期中の端末では、確認のため**30秒以内に2回押す**必要がある

### 知っておくべきこと

- 移行後も**従来の個人リンク（?w=…）はそのまま使える**（dual-accept）。他の端末やブックマークは壊れない
- 移行は「引き継ぎ方法を追加する」操作であり、漏れた個人キーを無効化するものではない。キーを知られた恐れがある場合は従来どおり「新しい個人キーを発行」を使う
- 単語・学習履歴はコピーも変換もされない（同じデータをそのまま参照する）
- 「新方式は現在準備中です」と出た場合は受付フラグOFF、「制限中」と出た場合は1時間ほど待って再試行

## 既存ユーザーへの案内文（コピー用）

> WordBankに、より安全な同期方式を追加しました。
>
> これまでは、アドレスバーのURLに個人キーが含まれていて、そのURLを知っている人は
> あなたの単語帳を読み書きできてしまう作りでした。新方式では、その秘密がURLに載りません。
>
> **移行は任意で、急ぎでもありません。** しなくても今までどおり使えますし、
> データが消えることもありません。今後アプリを更新しても、
> お使いのリンクはそのまま使い続けられます。
>
> 移行する場合:
> 設定 →「データの保存・引き継ぎ」→「新方式（V2）の同期と引き継ぎ」→「新方式へ移行」
>
> 移行すると **引き継ぎコード**（`wr_…` で始まる文字列）が表示されます。
> 機種変更や、サイトデータを消してしまったときに使うものなので、
> 「テキストで保存」かJSONの書き出しで、端末の外に保管しておいてください。
> （コピーするだけだと、貼り付け先が残っていないと意味がありません）
>
> なお、移行しても**今お使いの個人リンクは引き続き有効**です。
> 万一コードをなくしても、そのリンクからアクセスできます。
> ただしコードの再発行はできないので、保管しておくのが安心です。
>
> うまくいかない場合や、表示がおかしい場合は教えてください。

### 案内するときの注意

- **「紛失すると復旧できません」と書かない**。それは新規発行（create）で得たコードの話で、
  移行（upgrade）で得たコードには当てはまらない。アプリ内の文言も
  `origin` で出し分けており、案内文だけ強い書き方をすると食い違う
- 移行を急かさない。既存ユーザーにとっての実利は「URLに秘密が載らなくなる」ことだけで、
  データ保全上の必要性はない
- 新規ユーザーへのV2既定化（Phase 2）は**既存ユーザーには適用されない**。
  聞かれたら「新しく使い始める人の初期設定が変わるだけ」と答える

## 開発者向けメモ（運用）

- 鍵リング `~/.wordbank/sync-auth-secrets.json` はサーバー側のHMAC鍵。**ユーザーには渡さない**。
  紛失＋Cloudflare側の事故が重なると全V2部屋が認証不能になるため、パスワードマネージャへ二重保管する
- ユーザーが保管するのは従来どおり「個人リンク」と「JSONバックアップ」、加えて移行した場合のみ「引き継ぎコード」
- 移行状況の確認:
  ```sh
  npx wrangler d1 execute wordbank --remote --command \
    "SELECT COUNT(*) AS rooms, SUM(upgraded_from_legacy) AS upgraded FROM rooms"
  ```
  2026-07-25時点: rooms 13 / upgraded 2。ただし13件のうち11件は当日の検証で作った
  create由来の部屋で、**実利用者の移行は開発者の1件のみ**。他の既存ユーザーはlegacyのまま
- 利用状況のあたり:
  ```sh
  npx wrangler d1 execute wordbank --remote --command \
    "SELECT COUNT(*) FROM states WHERE updatedAt > strftime('%s','now','-7 day')*1000"
  ```
  検証用のキーも混ざるため、実利用者数の代用にはならない点に注意
